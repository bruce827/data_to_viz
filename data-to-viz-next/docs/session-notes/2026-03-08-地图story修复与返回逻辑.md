# 2026-03-08 地图 Story 修复与返回逻辑记录

## 本次完成内容
1. 补齐地图决策树剩余 story 页面
- 新增并接通以下页面：
  - `/graph/hexbin_map`
  - `/graph/gridheatmap`
  - `/graph/pathmap`
  - `/graph/flowmap`
  - `/graph/contourmap`
  - `/graph/background_map`
  - `/graph/map3dfill`
- 同步补齐 `src/data/tree-maps.json` 中缺失的 `storyPath`。

2. 修正分级统计图（`chart-background`）story
- 交互示例替换为用户指定图片资源。
- 应用场景图从“只有边界”的图改为行政区划面填色图。
- 省级区划 GeoJSON 改为本地资源，避免远程数据不稳定导致填色缺失。

3. 重构六边形地图（`chart-map-hexbin`）story
- 应用场景图按用户要求改为“中国蜂窝轮廓 + 热点蜂窝覆盖”，不再使用真实行政区划底图。
- 交互示例和场景图所需蜂窝数据均切到本地文件，消除外网依赖。
- 处理了多轮错误修复：
  - 空白图：补回 `chart.render()`
  - 图形语义错误：将误做的行政区划底图改回中国蜂窝轮廓
  - 热点不落在对应蜂窝：底图层与热点层统一 `binWidth: [2, 3]`
  - 交互示例缺轮廓：补齐中国蜂窝轮廓/底板

4. 修正网格热力图（`chart-map-grid-heatmap`）story
- 应用场景图按交互示例思路重做为 `grid` 聚合 + 点位叠加。
- 明确了颜色语义：
  - 面颜色表示 `sum(risk_weight)`
  - 点颜色表示 `anomaly_band`
- 补上离散图例分档。
- 通过缩小网格尺寸、收紧地图视角、增强面层色阶、弱化点层，解决“只能看到点看不到面”的问题。

5. 修复 story 页“返回决策树”逻辑
- `StoryLayout` 不再固定跳 `/`，而是根据当前 story 页推导并跳回对应决策树 tab。
- 首页改为支持通过 `?tab=` 查询参数切换树类型。
- 对复用同一路由的页面补充显式 `decisionTreeTab`，避免回错树：
  - `parallel` -> `cat`
  - `chord` -> `cat`
  - `network` -> `cat`
  - `arc` -> `catnum`
